  chmod 755 .
  chmod 644 index.html style.css portal.html

Your expected links are:

If your CODD username or class folder is different, update only that part of the URL.

GITHUB + PULL REQUEST WORKFLOW
------------------------------
1. Create a new public GitHub repository, for example: nirupam-portfolio
2. In Git Bash or VS Code Terminal, run:

   git clone https://github.com/ChNirupam/nirupam-portfolio.git
   cd nirupam-portfolio

3. Copy index.html, style.css, and portal.html into the cloned folder.
4. Create a branch and push it:

   git checkout -b portfolio-homepage
   git add index.html style.css portal.html
   git commit -m "Build personal full stack portfolio"
   git push -u origin portfolio-homepage

5. Open https://github.com/ChNirupam/nirupam-portfolio
6. Click "Compare & pull request."
7. Use this pull request title:
   Build Nirupamarayudu Chitturi personal portfolio
8. Add a short description, then click "Create pull request."
9. Review the changed files and click "Merge pull request" and "Confirm merge."

If you are updating an existing repository, open that repository first and use
its URL in the git clone command. Do not create a second repository unnecessarily.
